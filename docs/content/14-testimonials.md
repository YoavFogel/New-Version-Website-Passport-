# לקוחות מספרים: משפחות שעברו איתנו את התהליך

כל משפחה מגיעה עם סיפור אחר. ביקשנו מכמה מהלקוחות שלנו לספר איך היה.

### Card template
> "[ציטוט, 2–4 משפטים. רצוי שיתאר משהו ספציפי: שאלה שקיבלה מענה, בעיה במסמכים שנפתרה, עדכון שהגיע בזמן]"
> **[שם פרטי + אות ראשונה של שם המשפחה]**, [עיר] · [סוג התיק: למשל "אמא וארבעה ילדים", "שורשים בבסרביה"] · [שנה]

### Case story template (optional)
**משפחת [X]: סבתא מבלץ ושמות שלא תאמו**
- **המצב:** [...]
- **האתגר:** [...]
- **מה עשינו:** [...]
- **התוצאה:** [...] *(only real outcomes, with consent)*

### Editorial rules
- Only real clients, with written consent (keep the consent on file).
- Edit only for length and typos. Don't change meaning.
- Prefer testimonials that mention **specific behaviors** (updates, honesty, how a problem was solved) over generic praise.
- Don't publish testimonials that promise timelines or guaranteed results ("קיבלנו תוך 6 חודשים!") without context, or at all. They create expectations we can't control.
- Show the year, so that old testimonials aren't read as current timelines.
